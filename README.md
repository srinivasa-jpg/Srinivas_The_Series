# SRINIVAS — THE SERIES

A cinematic, streaming-inspired **mechanical engineering portfolio** adapted for **Ammika Srinivas** from the supplied resume. Includes teaching experience, education, selected research papers, professional development programs, mechanical engineering skills, a portrait, and a public-friendly downloadable resume.

## Start locally

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal. To check a release build: `npm run build`. To preview it: `npm run preview`.

## Personalize

- Edit `src/data/portfolio.ts` for all facts: contact details, education, experience, selected publications, workshops, skills, seasons and slides.
- Replace `pic1.jpeg` (your source photo) and `pic.png` (your portrait cutout), then run `npm run images` to refresh WebP portraits and share image.
- The public-friendly resume is `public/assets/Ammika_Srinivas_Portfolio_Resume.pdf`. Update it when your career details change.
- Your GitHub profile is `https://github.com/srinivasa-jpg`; your LinkedIn URL was not provided and is intentionally hidden until added.
- For privacy, the publicly accessible PDF omits the precise street address and mobile number found in the uploaded source resume.
